# 7. Testing Documentation

## How to run (exactly as executed during development)
```bash
# Backend (Maven + JUnit 5)
cd backend && mvn test
# Frontend (Vitest)
cd frontend && npm install && npm test
```
> **Verification note.** In the authoring sandbox Maven Central was unreachable, so the 56 JUnit 5 tests were compiled with `javac` (JDK 21) and executed with the **real JUnit Platform Console launcher** against the pure-Java packages (`engine`, `sim`, `csv`, `bench`): `56 tests successful, 0 failed`. `mvn test` itself and the Spring layer were **not** executed there — run them locally (see README) and treat any failure as a defect to report.
> Frontend: `npm test` → 17 passed; `npm run build` succeeded.

## Frontend tests (17)
`util.test.js` (CSV quoting/injection, layout hiding, frame timeline). `FlowGraph.test.jsx` renders the component from **real engine traces** (`src/test-fixtures/*.json`, generated by `backend/tools/TraceFixture.java`) and checks path highlighting length, min-cut edge count and that a reverse arc occurs in the greedy-trap trace.
Regenerate fixtures: `javac -cp <classes> backend/tools/TraceFixture.java && java -cp <classes>:. TraceFixture greedy-trap frontend/src/test-fixtures/greedy-trap.trace.json`.
